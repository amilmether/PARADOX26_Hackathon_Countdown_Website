# PARADOX '26 Hackathon Countdown

Retro 8-bit themed countdown website for the PARADOX '26 8-hour inter-college hackathon.

## Files
- index.html
- style.css
- script.js

## Run
Open `index.html` in a browser.

## Change the countdown time
Open `script.js` and edit:
`const HACKATHON_START = new Date("2026-09-17T10:00:00+05:30").getTime();`

Replace 10:00 with the official hackathon starting time.
